# ScaleCheck: An OIN Diagnostic for Pilot-to-Production Readiness

An interactive diagnostic tool operationalizing the OIN framework
(Ownership, Integration, Narrative) from the whitepaper "Stalled
Pilot-to-Production Conversion Amid Economic Tightening."

## How it maps from paper to app
- Ownership Dissolution risk ← Ownership + Governance dimension scores
- Integration Tax risk ← Integration + Transformation dimension scores
- Narrative Capture risk ← Financial Value dimension score

## Stack
React + Vite (frontend), Flask (backend), MongoDB Atlas (storage)
